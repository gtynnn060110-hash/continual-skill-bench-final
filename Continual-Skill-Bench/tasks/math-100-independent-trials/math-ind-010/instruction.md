## Task 10 [L2] [aime] [polynomial, olympiad_algebra]

Let $\omega\neq 1$ be a 13th root of unity. Find the remainder when
\[\prod_{k=0}^{12}(2-2\omega^k+\omega^{2k})\]
is divided by 1000.

Output requirements:
- Write your answer to `/app/task_010_output.json`
- JSON object with at minimum:
  - `answer`: a short plain string (e.g. `"A"`, `"540"`, `"\\frac{{1}}{{2}}"`). For multiple values use ` | ` as separator. No nested objects.
- Optional fields: `reasoning`, `steps`. The `answer` field must directly answer the question.
